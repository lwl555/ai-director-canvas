豆包文生图

火山引擎豆包（Doubao）独立生图
💡 不想配 Key？用「AI视频制作-小林」或「AI助手」也能免 Key 直接出图/出视频。豆包通道适合需要火山引擎 Seedream 专属模型的场景。
Key 只存你自己的浏览器（localStorage），不进源码/不进 git。部署后是公开页面，明文写进去会被人偷走。
当前比例：2048×2048（1:1 方形）
选一张图作为比例参考（生成图会按它的宽高比输出；留空则默认 2048×2048）
模型填「推理接入点 ID」（形如 ep-20250xxxx，不是模型名）。创建路径：火山引擎控制台 → 方舟 Ark → 推理接入点 → 从 Seedream 图像模型新建，把得到的 ID 粘到这里。
填好 Key、接入点 ID 和提示词，点生成。

豆包图生图（以图改图）

可上传多张参考图 + 写要求，按豆包 Seedream 改图
叠加更改：勾选「以最近生成的图为底图」后，下一张会基于上一张继续改（就像豆包 App 的「继续编辑」）。比例：选「按参考图比例」则保持原图比例；选其他比例会先把参考图裁到目标比例再生成，保证出图比例就是你选的。
